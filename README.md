# Luxury Wedding Invitation Website

## Quick edit
Open `config.js` and change the wedding details. Put your files in `assets/` using the names below.

- `music.mp3`
- `hero.jpg`
- `photo1.jpg` through `photo6.jpg`
- `final.jpg`

Then open `index.html` in a browser or upload the folder to GitHub Pages, Netlify, Cloudflare Pages, etc.

## QR note
The QR image uses the QR Server API at runtime. If you need a completely offline version, generate a QR PNG for the final map URL and replace the `renderQR()` function in `script.js`.
